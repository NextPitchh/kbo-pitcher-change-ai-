## 추가 진단: 이닝별 비단조성의 원인

원 데이터 기준 이닝별 평균 leverage_index가 단조 증가하지 않은 이유를 조사했다.

이닝별 평균 |score_diff_attacker| (경기가 진행될수록 점수차가 자연스럽게 벌어짐):
```
1회: 0.50   3회: 1.82   5회: 2.66   7회: 3.31   9회: 3.81
```

"후반 이닝일수록 같은 상태의 LI가 오른다"는 효과와 "후반 이닝일수록 점수차가
벌어져 LI가 낮아진다"는 효과가 반대 방향으로 겹쳐, 중반(4~8회) 평균이
눌린 것으로 확인됨.

접전 상황(|score_diff_attacker|<=1)만 필터링해 재확인:
```
1회: 1.14   2회: 1.10   3회: 1.10   4회: 1.21   5회: 1.35   6회: 1.49   7회: 1.62   8회: 1.64   9회: 2.41
```

점수차 요인을 통제하니 거의 단조 증가로 회복됨 (1→2회 사이 미세한 하락 제외).
결론: leverage_index 계산 자체는 정상이며, 원 데이터의 비단조성은 점수차
분포가 이닝에 따라 실제로 변하는 교란 요인 때문임 — 계산 로직 결함 아님.
